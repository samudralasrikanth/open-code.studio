# @ocs/common

Shared common types and utilities.

## Purpose

This package is part of the Open-Code.Studio repository foundation. It owns its documented domain boundary and exposes public APIs only through `src/index.ts`.

## Core Platform Services

- `@ocs/common/di` provides dependency injection.
- `@ocs/common/config` provides validated configuration.
- `@ocs/common/logger` provides structured logging.
- `@ocs/common/events` provides asynchronous messaging.
- `@ocs/common/errors` provides standardized platform errors.
- `@ocs/common/lifecycle` provides startup, shutdown, and health checks.
- `@ocs/common/telemetry` provides counters, gauges, and timers.
