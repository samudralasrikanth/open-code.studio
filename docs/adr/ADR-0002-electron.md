# ADR-0002-electron — Electron

## Status

Accepted

## Context

The project required a long-term architectural decision in this area.

## Decision

Adopt Electron as the desktop runtime to provide cross-platform support and access to native operating system capabilities.

## Consequences

### Positive

- Consistent engineering approach
- Easier maintenance
- Clear architectural direction

### Negative

- Introduces long-term commitment
- Future migrations require planning

## Alternatives Considered

- Keep existing approach
- Choose a different technology
- Defer the decision
