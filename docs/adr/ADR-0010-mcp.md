# ADR-0010-mcp — Model Context Protocol

## Status

Accepted

## Date

2026-07-03

## Context

A strategic architectural decision was required to support long-term maintainability and evolution.

## Decision

Adopt MCP as the standard protocol for integrating external tools, resources, and prompts with AI capabilities.

## Rationale

- Scalability
- Maintainability
- Extensibility
- Reliability

## Consequences

### Positive

- Consistent engineering direction
- Simplified future enhancements
- Better contributor guidance

### Trade-offs

- Additional implementation effort
- Ongoing maintenance responsibility

## Alternatives Considered

- Simpler implementation
- Different technology
- Deferred decision
