# ADR-0015-vscode-compatibility — VS Code Compatibility

## Status

Accepted

## Date

2026-07-03

## Context

A strategic architectural decision was required to support long-term maintainability and evolution.

## Decision

Provide pragmatic compatibility through adapter layers while keeping the core architecture independent.

## Rationale

- Scalability
- Maintainability
- Extensibility
- Reliability

## Consequences

### Positive

- Consistent engineering direction
- Simplified future enhancements
- Better contributor guidance

### Trade-offs

- Additional implementation effort
- Ongoing maintenance responsibility

## Alternatives Considered

- Simpler implementation
- Different technology
- Deferred decision
