# ADR-0003-react — React

## Status

Accepted

## Context

The project required a long-term architectural decision in this area.

## Decision

Use React for renderer UI because of its mature ecosystem, composability, and compatibility with Monaco-based applications.

## Consequences

### Positive

- Consistent engineering approach
- Easier maintenance
- Clear architectural direction

### Negative

- Introduces long-term commitment
- Future migrations require planning

## Alternatives Considered

- Keep existing approach
- Choose a different technology
- Defer the decision
