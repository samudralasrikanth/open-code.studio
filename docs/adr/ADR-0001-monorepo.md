# ADR-0001-monorepo — Monorepo

## Status

Accepted

## Context

The project required a long-term architectural decision in this area.

## Decision

Use a single repository to host applications, shared packages, extensions, tooling, and documentation to enable consistent versioning and refactoring.

## Consequences

### Positive

- Consistent engineering approach
- Easier maintenance
- Clear architectural direction

### Negative

- Introduces long-term commitment
- Future migrations require planning

## Alternatives Considered

- Keep existing approach
- Choose a different technology
- Defer the decision
